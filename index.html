Требуемые управленческие действия

Это не выводы о виновных или факте задержки — только вопросы, которые данные ещё не закрывают.

  1. 1Подтвердить актуальный прогноз. Текущий КСГ переносит передачу относительно базовой версии; необходимо подтвердить основание переноса и решение по сроку.
  2. 2Закрыть факт по начатым работам. Для работ с фактическим началом, но без даты окончания требуется внести статус и прогноз завершения в ежедневный мониторинг.
  3. 3Добавить освоение бюджета. Для раздела план/факт нужны исходные данные по бюджету; без них финансовые показатели на странице не рассчитываются.
